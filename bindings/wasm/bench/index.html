diffyman WASM bench

Loads ../pkg-web, diffs /data/{size}mb-left.txt against /data/{size}mb-right.txt once cold and then runs more times, and writes the timings below. Query parameters: size (default 1), runs (default 5), pkg (where the .wasm comes from, default ../pkg-web; the JavaScript glue always comes from ../pkg-web, so the module must be built from the same source). Serve it with serve.py.
