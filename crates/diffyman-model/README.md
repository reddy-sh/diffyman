# diffyman-model

The Diff Document types of [diffyman](https://github.com/reddy-sh/diffyman): Rust types for
every field, the canonical JSON writer (RFC 8785) and the JSON Schema.

This is a building block of the [`diffyman`](https://crates.io/crates/diffyman) engine, which
re-exports it as `diffyman::model`. Depend on `diffyman` unless you only need the types; the
two are released together with the same version.

- [Documentation](https://reddy-sh.github.io/diffyman)
- [Diff Document specification](https://github.com/reddy-sh/diffyman/blob/main/docs/spec/diff-document.md)
