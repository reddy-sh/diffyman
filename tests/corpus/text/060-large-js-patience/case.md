# 060-large-js-patience

A generated JavaScript module of 360 small functions (3600 lines, about 82 KB), run with `algorithm: "patience"`. Most lines repeat in every function (`const result = [];`, `  }`, `return result;`, blank lines), and only the header and the `limit` line of each function are unique, which is where patience anchors. Edits: one line of function 50 changed, function 120 deleted, a new function inserted after function 200, and two lines of function 250 changed. A correct result has four hunks with five change ops (the two edits of function 250 are separate `replace` ops around one equal line); the deletion takes the whole function with its blank line (L1201-1210) and the insertion is 4 lines, as git's patience diff gives. Stats: `linesAdded: 7`, `linesRemoved: 13`, `linesUnchanged: 3587`.
